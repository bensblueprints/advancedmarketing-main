Clickmap Review: the Pay-Once Heatmap Tool for Marketers

By Advanced Marketing · 2026-07-27 · Filed under pay-once tool reviews

Clickmap is a $129, pay-once heatmap tool that positions itself against Hotjar ($39/mo). The short version, after running it through real client work: for most marketing teams it pays for itself almost immediately. Two months of Hotjar buys Clickmap outright, and it never prices you by the session again.

But "replaces Hotjar" deserves an honest look rather than a cheer. Full disclosure up front: we distribute Clickmap through OneTimeSuite, so factor that in. Here is what it does well, where it falls short, and who should keep paying Hotjar.

What you get for $129

Click heatmaps and session replay you own forever. Self-hosted click heatmaps, scroll depth and session recordings, all in your own SQLite file.

  • One-tag install — Drop a single defer script tag with your site key and start collecting.
  • Click heatmaps — Click density on a proportional page canvas, per URL, filterable by device and date range, with a most-clicked elements list.
  • Scroll-depth chart — See what percentage of visitors reach each 10% fold of the page.
  • Session recordings — Lightweight click/cursor/scroll event stream with a replay player: play/pause, scrubbing, 0.5-4x speed.
  • Rage-click detection — Three-plus clicks in the same spot within a second auto-flags the session; filter recordings to rage sessions only.
  • Input recording is impossible — The tracker has no code path that reads input values or keystrokes — the capability does not exist, so it cannot be misconfigured.
  • DNT/GPC respected twice — The tracker no-ops when Do Not Track or Global Privacy Control is set, and the server drops flagged payloads anyway.
  • Compressed storage — Session event streams are gzipped in SQLite to keep data volume down.

How agencies put it to work

  • Client work: One-tag install — drop a single defer script tag with your site key and start collecting, and there is no per-seat cost when the whole team piles in.
  • Campaign production: Click heatmaps — click density on a proportional page canvas, per URL, filterable by device and date range, with a most-clicked elements list, which means one less shared login and one less quota to babysit.
  • Reporting & handoff: Scroll-depth chart — see what percentage of visitors reach each 10% fold of the page, so the tenth revision costs the same as the first — nothing.
  • Retainer margins: Session recordings — lightweight click/cursor/scroll event stream with a replay player: play/pause, scrubbing, 0.5-4x speed, and every deliverable stays under your agency’s brand, not a vendor’s.
  • Volume days: Rage-click detection — three-plus clicks in the same spot within a second auto-flags the session; filter recordings to rage sessions only, which keeps client data on hardware you control instead of a third-party cloud.

The verdict

Who Clickmap is for

Agencies and marketers who see what visitors click regularly and are tired of renting the capability. If the tool's job shows up in your week more than once or twice — client deliverables, campaign assets, reporting — the $129 one-time price is a rounding error against $468 a year for Hotjar. It is also the right pick if client data privacy matters to you: everything stays on your own hardware.

Who should stay on Hotjar

Teams whose workflow is genuinely built on Hotjar's cloud — shared workspaces, its specific integrations, clients who log in there directly. If switching would cost you more in retraining and process change than $468 a year, stay put. And if you only track visitor clicks once a quarter, a free tier somewhere may be all you need; buy Clickmap when the job becomes routine.

Score it plainly: capability for the core job, 9/10. Convenience versus a hosted incumbent, 7/10. Value for money, 10/10 — $129 once against $39/mo is not close.

Common questions

Is it really free on GitHub?
Yes — Clickmap is MIT-licensed at github.com/bensblueprints/heatmap-session-recorder-mvp. The $129 buys the packaged Windows installer and updates; building from source is free.

Does it record what my users type?
No. The tracker has no code path that reads input values, textarea content or keystrokes — only element positions and short CSS selectors. It is physically incapable of recording typed input.

Is this a subscription in disguise?
No. $129 once, no renewal, no per-session pricing. Data never leaves your server, so you stay the sole controller.
